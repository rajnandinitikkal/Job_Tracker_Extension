#### Job Application Tracker – Chrome Extension
- Applying for jobs across multiple platforms often leads to accidentally applying for the same role more than once. This Chrome extension is designed to track applied jobs and their application dates, helping users avoid duplicate submissions.

##### Features:
1) Add a job by clicking the “+” button on the job application page
2) Automatically store the date of application

- On revisiting the same job:
1) Displays the applied date
2) Provides a delete option
3) View a list of all applied jobs with dates directly from the extension popup

🎯 Purpose:
To save time, reduce repetitive work, and maintain a clear record of job applications during the job search process.
🛠️ Use Case:
Perfect for candidates applying through multiple job portals where the same role may appear on different websites.
